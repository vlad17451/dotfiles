# tmux setup

Requires `tmux` and `git`.

```bash
git clone git@github.com:vlad17451/dotfiles.git ~/dotfiles
~/dotfiles/setup-tmux.sh
```

Then start `tmux`, or press `C-a r` inside a running one.

Config lives in `~/dotfiles/tmux.conf.local` (symlinked into `~/.config/tmux/`). Commit changes from `~/dotfiles`.
